# 답변 평가 Reference Score Rubric

Reference Score는 AI 결과를 보기 전에 사람이 확정하며, 모든 항목은 1~5점 정수로
평가한다. 초깃값을 사람이 검토하지 않았다면 Human Score라고 표현하지 않는다.

| 점수 | 공통 의미 |
|---:|---|
| 5 | 답변의 구체적인 사실과 근거로 매우 명확하게 확인됨 |
| 4 | 대부분 확인되지만 일부 세부 정보가 부족함 |
| 3 | 일부 확인되지만 설명이 일반적이거나 불완전함 |
| 2 | 관련 표현은 있으나 평가 근거가 매우 부족함 |
| 1 | 답변에서 확인되지 않거나 질문과 무관함 |

## 항목별 판단

- `relevance`: 질문이 묻는 내용을 직접 답했는지만 본다. 자세하지만 엉뚱하면 낮다.
- `specificity`: 상황·사례·기술·수치 등 식별 가능한 세부 정보가 있는지 본다.
  결과 수치가 없다는 이유만으로 이 항목까지 자동 감점하지 않는다.
- `logical_structure`: 설명의 순서와 인과관계를 이해할 수 있는지 본다.
  STAR 형식을 그대로 따르지 않아도 흐름이 명확하면 높게 평가한다.
- `role_clarity`: 팀 전체가 아니라 지원자 본인의 책임과 기여가 드러나는지 본다.
- `action_clarity`: 지원자가 실제로 한 행동과 판단이 구체적인지 본다.
- `result_clarity`: 결과·성과·검증 또는 학습이 명확한지 본다. 정량 수치가 있으면
  강한 근거지만, 검증 가능한 정성 결과도 인정한다.

한 항목의 약점을 다른 항목에 자동으로 중복 감점하지 않는다. 예를 들어 정량 성과가
없어도 사용 기술과 행동이 구체적이면 `specificity`와 `action_clarity`는 높을 수 있다.

## 검토 절차

1. 질문과 답변만 읽는다.
2. 여섯 항목을 서로 독립적으로 채점한다.
3. Evidence와 Missing Point가 실제 답변과 맞는지 확인한다.
4. AI 출력은 보지 않은 상태에서 점수를 승인한다.
5. 애매한 사례는 메모에 판단 이유를 남긴다.
